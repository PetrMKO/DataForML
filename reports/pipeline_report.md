# Pipeline Report: news classification

## 1. Описание задачи и датасета
- **Задача:** classification
- **Предметная область:** news classification
- **Финальный датасет:** `data/labeled/`
- **Размер:** 4000 примеров (train: 3200, test: 800)
- **Классы:** World (56.7%), Sports (22.2%), Business (13.9%), Sci/Tech (7.2%)
- **Источники:** AG News (HuggingFace) — академический датасет новостей Reuters/AP

## 2. Что делал каждый агент
- **DataCollectionAgent:** загрузил ag_news train (3000) + test (1000) из HuggingFace → `data/raw/` (4000 строк, 0 дублей)
- **DataQualityAgent:** severity=low, проблем не найдено, датасет остался 4000 строк → `data/clean/`
- **AnnotationAgent:** rule-based классификация (torch не установлен, BART недоступен); флагнуто 1984 (49.6%) примеров с confidence < 0.85 → `data/annotated/`
- **ALAgent:** entropy vs random, 5 итераций по 310 примеров; entropy F1=0.5935 vs random F1=0.4439 (+Δ0.15) → `data/final/`
- **ModelTrainer:** TF-IDF (max_features=10000, ngrams=(1,2)) + LogReg (C=1.0), split 80/20

## 3. Human-in-the-Loop точки
### HITL-1: Проверка разметки

### HITL-2: Подтверждение датасета

## 5. Ретроспектива

**Что сработало хорошо:**
- AG News — хорошо структурированный датасет с чёткими тематическими категориями
- Entropy AL стратегия дала +15% прирост F1 по сравнению с random на том же объёме данных
- DataQualityAgent корректно определил severity=low и не внёс лишних изменений

**Что не сработало:**
- Rule-based разметка создала дисбаланс (World=56.7% вместо ~25%) из-за пересечения ключевых слов
- Sci/Tech recall=0.10 — модель почти не распознаёт этот класс из-за малого количества примеров
- 49.6% флагнуто для HITL, но проверка была пропущена — это повлияло на качество

**Что сделал бы иначе:**
- Установить torch + transformers для zero-shot BART — снизит флагнутые до ~15%
- Не пропускать HITL-1 — ручная правка 1984 примеров улучшила бы F1 на +10-15%
- Добавить балансировку классов (oversample) для Sci/Tech перед обучением

**Дальнейшие шаги:**
- Установить `pip install torch transformers` и перезапустить с шага 3
- Попробовать DistilBERT вместо TF-IDF+LogReg (ожидаемый F1: 0.85+)
- Расширить датасет через scraping реальных новостных сайтов
